# dashcn registries

> List configured and discoverable registries.

## Usage

```bash
dashcn registries [--json]
```

## Arguments

This command does not define positional arguments.

## Flags

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--json` |  | `false` | Output machine-readable JSON. |

## Examples

```bash
dashcn registries
```
