# dashcn docs

> Regenerate command reference documentation.

This command requires `--advanced`.

## Usage

```bash
dashcn --advanced docs [--generate]
```

## Arguments

This command does not define positional arguments.

## Flags

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--generate` | `-g` | `false` | Regenerate doc/reference/commands. |

## Examples

```bash
dashcn --advanced docs --generate
```

## Notes

This command requires --advanced.
