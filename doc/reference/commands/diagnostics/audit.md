# dashcn audit

> Compare installed files against dashcn.lock.

## Usage

```bash
dashcn audit [--json]
```

## Arguments

This command does not define positional arguments.

## Flags

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--json` |  | `false` | Output machine-readable JSON. |

## Examples

```bash
dashcn audit
```
