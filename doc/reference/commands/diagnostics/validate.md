# dashcn validate

> Validate the registry manifest against the v2 schema.

## Usage

```bash
dashcn validate [--json]
```

## Arguments

This command does not define positional arguments.

## Flags

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--json` |  | `false` | Output machine-readable JSON. |

## Examples

```bash
dashcn validate
```
